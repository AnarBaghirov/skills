# clear-writing-ru — «Ясный текст»

[Навык](SKILL.md) помогает писать и редактировать русскоязычные тексты с учётом задачи, читателя и авторского голоса. Подходит для писем, статей, инструкций, учебных материалов, технических и деловых документов.

Три режима работы:

- **Написать:** собрать текст из фактов, заметок, расшифровки или задания.
- **Отредактировать:** улучшить содержание, логику, структуру и язык с нужной глубиной вмешательства.
- **Разобрать:** показать проблемы, предложить примеры «было → стало» и объяснить правки.

Навык помогает сохранять существенные факты, условия, ограничения и степень уверенности. Краткость служит ясности: если читателю нужны пояснения или примеры, текст может стать длиннее. Проверка фактов подключается, когда она нужна для задачи; сама редактура её не заменяет.

Навык не предназначен для автоматической переработки обычных ответов, перевода, чистой корректуры или художественной стилизации без отдельного запроса на содержательную редактуру.

## Установка в Codex

### Через skill-installer

Отправьте в чат Codex:

```text
$skill-installer Установи навык clear-writing-ru из https://github.com/AnarBaghirov/skills/tree/master/clear-writing-ru
```

Если установленный навык не появился, перезапустите Codex.

### Вручную: macOS и Linux

Понадобится Git. Команды ниже клонируют репозиторий в `~/codex-skills` и создадут ссылку на навык в пользовательской папке `~/.agents/skills`:

```sh
git clone https://github.com/AnarBaghirov/skills.git "$HOME/codex-skills" &&
mkdir -p "$HOME/.agents/skills" &&
ln -s "$HOME/codex-skills/clear-writing-ru" "$HOME/.agents/skills/clear-writing-ru"
```

Этот вариант рассчитан на первую установку: папка `~/codex-skills` и ссылка `~/.agents/skills/clear-writing-ru` должны быть свободны. Сохраните клонированный репозиторий: ссылка указывает на файлы внутри него.

Для установки только в одном проекте поместите папку `clear-writing-ru` целиком в `.agents/skills/` этого проекта.

Папки обнаружения навыков и поддержка символических ссылок описаны в [официальной документации OpenAI](https://learn.chatgpt.com/docs/build-skills).

## Установка в Claude Code

Используется та же папка `clear-writing-ru` с `SKILL.md` и вспомогательными файлами.

Для первой установки на macOS или Linux клонируйте репозиторий:

```sh
git clone https://github.com/AnarBaghirov/skills.git "$HOME/codex-skills"
```

Если репозиторий уже клонирован по инструкции для Codex, используйте существующую копию. Создайте ссылку на навык:

```sh
mkdir -p "$HOME/.claude/skills" &&
ln -s "$HOME/codex-skills/clear-writing-ru" "$HOME/.claude/skills/clear-writing-ru"
```

Путь `~/.claude/skills/clear-writing-ru` должен быть свободен. Сохраните клонированный репозиторий: ссылка указывает на файлы внутри него.

Для одного проекта поместите папку `clear-writing-ru` целиком в `.claude/skills/` проекта. После установки введите:

```text
/clear-writing-ru Отредактируй текст ниже для новых сотрудников.
Сохрани все условия и исключения.

[Текст]
```

Папки установки, символические ссылки и вызов через `/имя-навыка` описаны в [документации Claude Code](https://code.claude.com/docs/en/skills).

## Установка в Claude: веб, Desktop и Cowork

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте его.
2. Создайте отдельный ZIP-архив папки `clear-writing-ru`. В корне архива должна находиться эта папка, а внутри неё — `SKILL.md`, `agents/` и `references/`.
3. В Claude откройте **Customize → Skills → + → Create skill → Upload a skill**, загрузите архив и включите навык.
4. Если требуется, включите создание и редактирование файлов в **Settings → Capabilities**.

Затем попросите: «Используй навык clear-writing-ru, чтобы отредактировать текст ниже», и приложите текст.

Подробнее — в [инструкции Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude). Установка в локальную папку Claude Code и загрузка в аккаунт Claude — отдельные способы подключения.

## Использование

В примерах ниже используется вызов Codex — `$clear-writing-ru`. В Claude Code замените его на `/clear-writing-ru`, а в Claude попросите использовать навык по имени. Приложите исходный текст или материалы; укажите читателя, цель, объём и желаемую глубину правки.

**Написать текст:**

```text
$clear-writing-ru Напиши письмо команде по заметкам ниже.
Цель — согласовать сроки. Тон спокойный и прямой, объём — до 150 слов.

[Заметки]
```

**Отредактировать:**

```text
$clear-writing-ru Отредактируй инструкцию для новых сотрудников.
Упрости формулировки, сохрани все условия и исключения.
Верни готовый текст.

[Текст инструкции]
```

**Разобрать:**

```text
$clear-writing-ru Разбери этот текст: покажи основные проблемы
и объясни несколько правок на примерах «было → стало».

[Текст]
```
